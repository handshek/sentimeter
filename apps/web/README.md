# Sentimeter Web

Next.js 16 public widget catalog and documentation, with unreleased hosted
analytics for development only.
From the repository root:

```sh
bun install
bun run dev
```

The public site needs no Clerk or Convex environment variables. The development-only
hosted dashboard, authentication, and parked widget lab require the configuration
described in [onboarding](../../docs/onboarding.md). Hosted providers are scoped to
those routes.

See the [project README](../../README.md), [contribution guide](../../CONTRIBUTING.md),
and [design system](../../DESIGN_SYSTEM.md).
