# Changelog

## 0.1.0

Initial public registry release.

- Install Emoji Feedback, Like / Dislike, and Star Rating as open React source
  through the shadcn registry.
- Use stacked and inline layouts with host shadcn themes, keyboard interaction,
  optional comments, and submission confirmation.
- Save feedback through a custom `submit` handler or complete locally.
- Browse live specimens, human documentation, Markdown endpoints, and `llms.txt`.
- Join the waitlist for unreleased hosted analytics when the site is configured.
